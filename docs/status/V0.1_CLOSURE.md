## Root Cause Analysis

### What Works:
1. ✅ Training pipeline (loss decreases smoothly)
2. ✅ Model architecture (TinyLlama 1.1B + LoRA)
3. ✅ Prompt formatting (system + user + assistant)
4. ✅ SQL syntax generation (SELECT, FROM, WHERE, etc.)

### What Doesn't Work:
1. ❌ Schema grounding (hallucinates tables/columns)
2. ❌ Multi-table JOINs (gets confused)
3. ❌ Complex queries (subqueries, aggregations)
4. ❌ Noisy data tolerance (learns bad patterns)

### Why:
**Training data has ~90% noise:**
- SQL doesn't execute on the provided schema
- Column names don't match schema
- Question-SQL misalignment
- Duplicate/contradictory examples

**Model learned:** SQL format (good)  
**Model didn't learn:** Schema-grounded SQL (needs clean data)

## Risks & Mitigations

### Risk 1: Data cleaning takes longer than expected
**Mitigation:** Start with bird23_filtered (6.6K) + mini_dev (1.5K) = 8.1K examples
- Already filtered
- Higher quality than full BIRD train
- Faster to process

### Risk 2: Model still doesn't generalize
**Mitigation:** 
- Add complexity stratification (ensure mix of simple/complex)
- Add domain stratification (ensure coverage of all domains)
- Consider curriculum learning (simple → complex)

### Risk 3: Training doesn't improve
**Mitigation:**
- Have baseline ready (v0.1-alpha)
- Can pivot to larger model (7B) if 1.1B is capacity-limited
- Can add more data (synthetic generation)

## Confidence Assessment

### Why I'm Confident:

1. ✅ **Model works** - Smoke test proves it generates SQL

3. ✅ **Data is the issue** - Noisy labels explain poor BIRD performance

### What Could Go Wrong:

1. ❌ Data cleaning reveals <5K usable examples (not enough)
   - **Fallback:** Augment with synthetic data
2. ❌ Clean data doesn't improve EX (hypothesis wrong)
   - **Fallback:** Try larger model (7B) or schema grounding (RAG)
3. ❌ Training takes too long (>7 days)
   - **Fallback:** Use subset (5K examples), extend timeline

### Most Likely Outcome:

**v0.2-beta achieves 50-60% SQL validity** (meets target) with 10K verified examples and 3000 training steps.
